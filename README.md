# Hi, I'm Godfrey

Software Engineering and Applied AI graduate interested in backend engineering, software architecture, full-stack development, and applied NLP.

## Featured Projects

### 🐄 [V-Vet](https://github.com/godfreydekew/v-vet)
AI-powered livestock health decision support system helping farmers record animal health, identify potential diseases, and access veterinary guidance.

**Tech:** Python · TypeScript · PostgreSQL · NLP · WhatsApp API · Azure · Docker

---

### 🚗 [Car Parking Management System](https://github.com/godfreydekew/car_parking_crm)
Full-stack CRM for managing parking bookings, vehicle check-ins and check-outs, invoices, payments, transfers, overstays, and business analytics.

**Tech:** Python · TypeScript · PostgreSQL · DigitalOcean · Docker · Brevo

---

### 🅿️ [OR Tambo Premium Parking](https://github.com/godfreydekew/car_parking_crm)
Customer-facing booking website for an airport parking service, allowing customers to book parking and connecting bookings to the management CRM.

**Tech:** Vite · TypeScript · Tailwind CSS · Docker · Vercel

---

### 🗳️ [SmartVote](https://github.com/godfreydekew/smartVote)
Blockchain-based voting platform supporting local and regional elections, with wallet-based voting restrictions and identity verification.

**Tech:** Solidity · Ethereum · React · Express.js · Thirdweb · Didit · Docker

---

### 💰 [AI-Powered Family Budget Adviser](https://github.com/godfreydekew/AI-powered-Family-Budget-Adviser)
AI-powered personal finance assistant that analyses spending, provides personalised budgeting advice, and helps users identify benefits they may be eligible for.

**Tech:** Python · TypeScript · LLMs · NLP · RAG · PostgreSQL · Docker
